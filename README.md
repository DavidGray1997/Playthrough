# Playthrough
Similar to letterboxd but for games

## Development workflow

The repository includes the personal SDLC skill suite in [`.agents/skills`](.agents/skills):

- Initiative coordination: `sdlc`.
- Requirements and decisions: `write-prd`, `resolve-questions`, `record-decision`.
- Design: `design-domain`, `design-ux`, `design-architecture`, `design-api`, `design-database`.
- Delivery and release: `write-backlog`, `record-verification`, `record-release`.
- Git delivery and privacy checks: `git-workflow`.

Each skill includes its instructions and available templates, references and agent metadata. Lifecycle records use the portable `docs/initiatives/<initiative>/` structure described by the skills.
